# Call-center operator fixes (2026-11-10)

These are fixes for the walk-through of operator №1 (`+998901004001`, backend role "Navbatchi yurist") and operator №2 (`+998901004002`). Screenshots are in `/tmp/lexflow/cc` and `/tmp/lexflow/cc2`. Open backend points are in `docs/LEXGO_FRONTEND_QUESTIONS_CALL_CENTER_2026_11_10.md`.

Verification: `tsc --noEmit`, eslint on every changed file (0 warnings), the vitest suite (615 tests, including the new `tests/unit/callCenterOperatorFixes.test.ts`) and the mocked Playwright spec `tests/e2e/cc-operator-fixes.spec.ts` (4 tests) all pass. Every command ran inside a 3 GB memory scope. Turbopack `next dev` gets OOM-killed at 3 GB on this project, so the e2e run used `next dev --webpack`. Nothing was run against the live accounts.
